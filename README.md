# RED-MED

Acceptance Tests en Gherkin del middleware de interoperabilidad RED-MED, que permite consultar por DNI la información clínica de pacientes entre el Hospital Nacional Dos de Mayo y el Hospital Nacional Arzobispo Loayza.

Curso 1ASI0786 Ingeniería de Requisitos, UPC.

## Contenido

La carpeta `features` contiene los archivos .feature de las user stories de las épicas EP01 Consulta clínica por DNI y EP02 Visualización de la ficha clínica, y de cuatro historias no funcionales.
